PxIgnis runs on **PxLuaNova**, a Lua 5.2 fork. This page documents
extensions that aren't part of standard Lua 5.2.

## Numbers

Numbers behave as in Lua 5.2: there is one `number` type, and there are no
Lua 5.3 integer/float semantics (no `//`, no bitwise operators, `/` and `^`
are always floating-point operations).

Internally a number is stored either as a 32-bit integer or as a double.
This is only a representation detail: a result that is a whole number in the
32-bit range (`2.0`, `10 / 2`) is stored as an integer, and anything else
(`0.5`, `2^40`, `2147483648`) as a double. Values never change what they
compare or print as because of this.

`math.type` exposes the representation:

```lua
print(math.type(3))       -- integer
print(math.type(10 / 2))  -- integer (5 is a whole number)
print(math.type(0.5))     -- float
print(math.type(2^40))    -- float (outside the 32-bit range)
print(math.type("3"))     -- nil (not a number)
```

Don't use it to tell `3` from `3.0`; they are the same value. Use it
only to check that a value is a number whose representation fits in an
integer.

## Standard library additions

These functions come from Lua 5.3+ and are not part of standard Lua 5.2:

| Function                    | Description                                                  |
|-----------------------------|--------------------------------------------------------------|
| `math.type(x)`              | `"integer"`, `"float"`, or `nil` if `x` is not a number      |
| `math.atan(y, x)`           | Two-argument arctangent                                      |
| `math.min(...)`             | Variadic minimum                                             |
| `math.max(...)`             | Variadic maximum                                             |
